# maui-unit-testing Skill Methodology Summary

xUnit testing guidance for .NET MAUI apps:
- Plain .NET TFM for desktop test host (net10.0).
- Abstract UI and platform dependencies behind interfaces or use headless test models.
- Directly exercise models, viewmodels, computation engines, and serialization.
- Test edge cases, boundaries, multi-player scaling, real-time recalculations, lifetime stats aggregation, and disk persistence serialization.
